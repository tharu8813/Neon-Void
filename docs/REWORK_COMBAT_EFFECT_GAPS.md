> 이 문서는 실제 배포 승인이나 보호막 최종 규칙 확정을 의미하지 않는다.

## 코드 경로 차이 주의

- **C #117**의 `plugin_b_live_runtime.gd` 독립 전투 상태 검증은 27개 중 23개가 합격했다. 다음 4개는 여전히 독립 경로의 미검증 항목: `nv_c_periodic_shield`, `nv_c_skill_shield`, `nv_r_dash_shield`, `nv_c_random_rare`.
- 실제 A 선택형 CPU 파일럿은 **B #119** `production_cpu_adapter.gd` → `c_effect_adapter.gd` → C `plugin_effect_runtime.gd`을 사용한다. 독립 C 경로와 생산형 B 경로는 같지 않으므로 23/27 테스트만으로 장면에서의 27종 실행을 증명할 수 없다.
- A의 `tests/rework/integration/provisional_shield_contract_cases.gd`는 **생산형 B의 실제 damage calculation과 HP ledger**를 사용한다. C가 tick / `skill_cast` / dash 이벤트에서 3개 보호막 제안을 발생시키고, B가 실제 true damage보다 먼저 적용해 체력을 보호하고 보호막 소진 후 추가 피해를 정상 전달하는지 확인한다. 이는 현재 코드의 **제안된 shield-first** 동작이 연결되어 있음을 뜻하며, 정식 승인된 방어 규칙/밸런스나 실기기 연출 완성을 뜻하지 않는다.
- 보호막 3종 중첩·유효시간·오버힐·피해 종류별 경감 순서·CC·흡혈·피해량 0에서의 on-hit와 proc 규칙은 아직 승인되지 않았다. 임의로 공식 확정하지 않는다.

## 무작위 레어 보상 경계

- GDD에서 **무작위 레어 플러그인 획득** 효과 방향은 확정돼 있지만, 구체 후보 우선순위·후보 소진 시 처리·레벨 2의 추가 수량·최종 UI/VFX는 여전히 미확정이다. **#121 초안**은 획득당 레어 1개를 지급하고, 현재 E가 보관한 레어 플러그인 레벨과 C 카탈로그 최대 레벨로 후보를 제한하며, 후보가 없으면 원본 카드 저장 자체를 거절한다. 초안이 곧 최종 밸런스 승인을 의미하지 않는다.
- **검증용 #121 E 계약:** `plugin_picked`에서 `nv_c_random_rare` 카드가 E 검증을 통과하면, E가 **동일한 원자적 Store 트랜잭션 안에서** 정렬된 정식 레어 후보 중 결정적 1개를 선택한다. `e_rare_bonus_v1`에 원본 카드 영수증→레어 ID·레벨·난수 정책·파생 영수증을 기록하고, 두 영수증을 저장한다. 저장 불확실 시 A는 게임을 멈추며 재추첨하지 않는다. CPU 파일럿은 E에 저장된 보너스를 조회한 뒤 B/C에만 반영한다.
- **중복 이벤트 정책:** C의 옛 `grant_rare`가 내보내는 `rare_reward_request`는 B에서 계속 거부되며, 보너스를 또 지급하지 않는다. E의 `plugin_picked` 트랜잭션만 레어 보너스를 확정한다. 원본 카드 선택에 없는 가짜 `plugin_picked` 이벤트를 생성하면 안 된다. 레벨 2 추가 지급 수량은 아직 구현하지 않는다.
- **추가 검증:** `rare_bonus_cases.gd`가 결정적 레어 후보, 중복 영수증, 후보 고갈, Lv2 초안 1회 지급, E 파일 저장/재읽기 및 `after_backup`·`after_primary` 장애 주입을 검증한다. `rare_bonus_pilot_smoke.gd`가 실제 B/C 전투 레벨과 E 영구 저장의 일치를 검증한다. 이는 직접 Windows로 플레이한 것과는 다르다.

## 이미 해결된 다른 P0 경계

- A 파일럿에서 **CPU 맵 생성보다 먼저** E가 해당 `map_seed` 및 `D-procedural-v1` 생성기 버전을 `checkpoint_region` 트랜잭션으로 저장·ACK한다. D는 ACK 없이 CPU 맵을 만들지 않는다.
- C 3장 카드, 단일 재추첨, RNG 상태를 E에 먼저 저장한 후 UI 공개; 획득은 `prepare → E commit → C confirm → B effect`.
- 통합 자동 테스트는 Windows/Linux headless이며 CPU 일반 조작감, GPU 렌더 타이밍, 오디오, 화면 해상도 및 장시간 8~12분 밸런스 테스트는 포함하지 않는다.
