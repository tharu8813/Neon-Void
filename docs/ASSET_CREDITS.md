## 새로운 에셋을 추가할 때

실제 채택할 에셋마다 `이름 / 제작자 / 다운로드 URL / 다운로드 시점 / 정확한 라이선스 / 상업 사용 가능 여부 / 원본 재배포 가능 여부 / 크레딧 표시 조건 / 프로젝트 경로`를 기록해야 해. 사용 권리가 불분명하면 배포본에 포함하지 않아. Unity 또는 Godot의 에셋 스토어에서 받았다는 사실만으로 소스 재배포가 허용되는 건 아니야.
