# World & Content Bible | v2.0

> **[확정]** 허브→메인보드→하드웨어 자유 선택, CPU/GPU/RAM/SSD/HDD 5종, 절차 맵, 하드웨어별 난이도/환경, 정화 후 철수, 최소 1곳 쉬움, 평균 8~12분/구역 목표. **아래 적·보스·목표·비율·맵 구조는 모두 [초안]**이며 기존 Godot 결과물이 아니다.

## 1. 지리/플레이 규칙

- **디펜더 허브:** 백신 생성/선택, 재분배·장착, 학습 플러그인 DB, 임무 터미널. 3D 공간 이동 필수. 길찾기는 간단, 터미널 UI는 빠르게.
- **메인보드:** 임무별 탐험 시작 공간, 5개 하드웨어 포털/연결 회로, 현재 임무 위험도/환경 패널. 최초 도입 적 소수로 조작 확인 [초안].
- **하드웨어 내부:** 모듈식 전투/지형 생성. 시작 → 특징 체험 → 2~3개 소목표 → 보스 → 정화 → 철수 또는 메인보드 귀환 → 다른 하드웨어. 임무 종료는 1개 이상 정화 뒤 철수 성공.
- **복수 하드웨어 진행:** 입장 순서는 자유, 이미 정화한 하드웨어의 완료 상태는 런 동안 유지. 같은 하드웨어 재방문과 철수 지점 연결 규칙은 [미확정]이므로 반복 보상 지급·중복 정화 금지.
- **지형:** 세계 좌표 `XZ`, 카메라 Y축 하향(탑다운), 주요 이동은 평면. 높이 있는 벽·장치·보스는 3D로 보이되 카메라가 시야를 잃지 않게 투명화/윤곽선 [초안].

## 2. 구역별 차별화 테이블 [초안 v0.2]

| 지역 | 핵심 동사 | 목표 후보 3종 | 기본 위험 | 적 성향 | 보스 컨셉 | 시각·사운드 |
|---|---|---|---|---|---|---|
| **CPU** | 수비·타깃 우선순위 | 연산 코어 방어 / 프로세스 격리 / 과열 밸브 차단 | 주기적 과열/코어펄스 | 다수 접근형·지원형 | **코어 워처**: 오버클럭 패턴 | 적색·흑연, 규칙적인 팬/클럭 |
| **GPU** | 회피·조준·공간 읽기 | 셰이더 오염점 제거 / 렌더 큐 정렬 / 광선 스위치 연결 | 레이저 스윕·정확한 장판 | 원거리·탄막·분열 | **렌더 옵저버**: 스캔+홀로그램 | 자홍·청보라, 선명한 전조음 |
| **RAM** | 진위 구분·적응 | 오염 페이지 찾기 / 가짜 인스턴스 정리 / 캐시 유출 차단 | 환영/재배열/재생성 | 복제·속박·지원형 | **메모리 리치**: 공격 복제·잔상 | 녹색·보라, 에코/글리치 |
| **SSD** | 빠른 이동·구간 연결 | IO 레일 활성화 / 쓰기 잠금 해제 / 노드 전달 | 레일 돌진·짧은 순환 장판 | 돌격·고속 원거리 | **스트림 인터셉터**: 돌진+궤도 | 청색·백색, 짧은 디지털 비프 |
| **HDD** | 위치 관리·장기전 | 손상 섹터 복구 / 헤드 정렬 / 회전축 방어 | 회전 구획·낙하 파편 | 중장갑·지역 점유 | **섹터 콜로서스**: 회전/압박 | 황동·주황, 기계 마찰/저음 |

### CPU 세부 전개 [초안]

- **진입 0~90초:** 접근형 적 + 코어 수비 장치. 경로 선택의 의미를 먼저 학습.
- **목표:** 한 번에 하나의 핵심 코어 방어로 시작 → 공격 속도가 빠른 바이러스 팩 처리 → 지원형 프로세스 우선 제거 → 과열 밸브 상호작용.
- **보스 패턴:** (1) 붉은 부채꼴 코어 열기, (2) 직선 펄스 회로, (3) 소환과 보호막 전환. 오버클럭 중 속도 증가, 대신 냉각 창으로 공격 기회.
- **반복 플레이 변주:** 코어 배치·접근 경로·보조 방어 장치 생성. '지켜야 하는 시설'이 전부 동일한 체력/동일한 위치로 나오지 않도록 한다.
- **합격:** 플레이어가 목표를 지키면서 이동/타깃 선택을 해야 하고 보스 페이즈가 일반 적의 HP 증가판과 달라야 한다.

### GPU 세부 전개 [초안]

- **진입:** 바닥에 예고선이 먼저 나타나고 실제 레이저 판정은 늦게 발생. 비디오 이펙트만 반짝이고 판정 없는 것 금지.
- **목표:** 전류 전환기/레이저 회전기/오염 셰이더 장치를 안전하게 끄거나 경로 바꿈.
- **보스:** (1) 세 방향 순차 광선, (2) 회전 팬형 안전 영역, (3) 가짜 잔상(진짜 판정의 위치를 식별 가능하게), (4) HP 전환 시 짧은 패턴 믹스. 모든 공격은 경고→활성→종료가 분명해야 한다.
- **합격:** 이펙트 품질 최저에서도 위험 영역이 명확하며 GPU 성능으로 피해 판정이 바뀌지 않는다.

### RAM 세부 전개 [초안]

- **목표:** 정보가 깜빡이는 메모리 슬롯 탐색, 진짜 위협을 구별, 상태 이상을 유도하는 캐시 유출 차단.
- **적:** 대상이 짧은 시간 복제되며 가짜는 처치 XP를 지급하지 않는다. 가짜·진짜 구분 단서(윤곽/발밑/소리)를 반드시 포함.
- **보스:** 이전 플레이어 공격 방향을 '재생'하는 반격, 복제체의 시간차 패턴. 시간 정지나 입력 차단 같은 강한 CC는 강인함·저항/회피창 검증 없이는 넣지 않는다.
- **합격:** 가짜 처치로 경험치 파밍 불가, 정지 상태에서도 설정 메뉴 접근 가능.

### SSD 세부 전개 [초안]

- **목표:** 레일을 짧은 시간에 연결하고, 이동 경로에 폭주 노드를 차단, IO 전송을 위한 세 구간 전환.
- **적:** 고속 돌진형·직선 탄환형. 공격은 빠르더라도 조작 지연·DPI 때문에 불가능한 난도가 되지 않아야 한다.
- **보스:** 직선 워프 예고 후 이동, 따라오는 노드 파형, 레일 재구성으로 안전 공간 축소·확대.
- **합격:** 빠른 이동이라는 정체성이 있지만 튕김/불가피 피격이 아닌 학습 가능한 대응 경로 존재.

### HDD 세부 전개 [초안]

- **목표:** 손상 섹터 세 곳 복구, 이동식 읽기 헤드 회피, 무거운 적을 쫓아내며 지점 점유.
- **적:** 중장갑·원거리 지대 점유·아군 버프형. 장기전이 단순히 적 HP만 크게 만드는 방식이어서는 안 된다.
- **보스:** 외곽/내곽 회전 구역, 커다란 충격파, 피할 수 있는 파편 낙하. 회전하는 지형 자체와 피격을 독립적으로 예고.
- **합격:** 맵이 넓어도 불필요한 빈 이동 없이 탐험/목표 배치 밀도가 유지됨.

## 3. 보스 전투 공통 계약 [초안]

각 보스는 **최소 3개의 형태가 다른 패턴 + 1개 지역 기믹 + 1개 페이즈 변화**를 목표로 한다. 기본 전개는 `입장 예고 → 0.8~1.5초 피할 수 있는 텔레그래프 (패턴별 가변) → 공격 판정 → 회복/반격 창 → 패턴 전환`.

- 공격의 안전 영역은 색만으로 구분하지 않고 **모양·선·시간 게이지**도 보여준다.
- 전조 시각 표시와 실제 충돌 볼륨이 일치. 보스 커스텀 이펙트/사운드를 제거해도 전투 판정 동일.
- 무적/방어 상태는 완전 면역 중인지 부분 경감인지 UI로 구분.
- 보스 중단/프로세스 종료/씬 전환/철수 직전 보상은 **저장 영수증과 상태 변경이 단일 승인 경로**를 따라야 한다.
- [미확정] 보스 보상의 구체 XP, 클리어 전투의 재진입 규칙, 장시간 보스 과부하 상태, 난이도에 따른 실제 HP/피해 배율.

## 5. 환경/난이도 세부 [확정 + 초안]

- **[확정] 환경 종류:** 이상없음, 변이발생 Lv.1~5, 스택오버플로우, 터널감염, 확산, 초기상태.
- **[확정] 터널감염:** 현재 **학습되지 않은 소지 플러그인** 1~2개 비활성 또는 부정 효과. 학습 출전분을 예외로 하는 상태 태그가 필요하다.
- **[확정] 변이발생:** 일부 개체 능력 상승/일반·레어 플러그인 1~2개 획득. 높은 변이 단계의 비율은 반복 의뢰와 함께 커질 수 있음.
- **[초안] 표시:** 하드웨어 게이트에서 환경 명칭/영향/대상/복구 가능 여부/구역 난이도를 볼 수 있다.
- **[미확정]** 환경 상호배타/중첩, 난이도 3·4·5단계 여부, 변이 단계 증가와 장기 의뢰 수의 정확한 관계.

**쉬움 보장 알고리즘 테스트 계약:** `missionSeed`로 5개 하드웨어 난이도 선정 → 결과에 Easy가 하나도 없으면 **결정적인 규칙**으로 1개를 Easy로 보정(어느 하드웨어인지는 시드 RNG로 선택). 10,000개 시드 [초안 테스트 수]에서 최소 1개 항상 통과해야 함. 난이도를 전부 Easy로 강제하지 않음.

## 6. 절차 생성: 지형을 바꾸되 길을 막지 않기 [개발 권장]

**초기 구현:** 모듈형 방/복도 또는 그래프 기반 셀 → 목표 지점·보스·철수 포인트 배치 → 장애물/NavMesh 갱신 → 시작/각 목표/보스/철수 동선 검증 → 결정론 시드 스냅샷. 최종 3D 프리팹/조명/벽은 통과한 그래프 위에 꾸미는 표현 단계.

`AreaSpec`의 필수 필드(초안): `hardwareId`, `generatorVersion`, `seed`, `sizeModifier`, `difficultyId`, `environmentIds`, `roomGraph`, `objectiveSpawns`, `bossSpawn`, `extractionSpawn`, `rewardRolls`. 바깥 게임의 `MissionDirector`가 상태를 관리한다.

**생성 시 반드시 검증:**
1. 시작 위치 → 필수 목표 전부 → 보스 위치 → 정화 후 철수 지점에 **플레이어 충돌 크기 기반의 연결 경로** 존재.
2. 플레이어/적 스폰과 함정 및 각 오브젝트 충돌 반경의 안전 분리. 초반 화면 밖 즉시 피해 금지.
3. 목표·보스·포털이 플레이 불가능한 벽/낭떠러지 안에 생성되지 않음.
4. 동일 `(seed, hardwareId, generatorVersion)`에서 게임플레이 지형·목표 위치 재현. VFX 랜덤은 독립 RNG.
5. 맵 크기 축소·확대 환경에서도 구역당 8~12분 목표를 지나치게 벗어나지 않음. 불가능한 시드가 있으면 **기록된 대체 시드**로 재생성하고 영수증에 생성 버전을 남김.
6. 목표가 파괴/완료되기 전에 보스·철수가 활성화되지 않음. 완료 보상은 반복 호출에도 정확히 1회.

## 7. 페이싱을 위한 10분 구역 예산 [초안]

| 구간 | 목표 시간 | 질적 요구 |
|---|---:|---|
| 시작·환경 적응 | 1.0분 | 기믹 1개를 미리 보여줌 |
| 일반 전투+2~3목표 | 5.5분 | 적 타입 2종 이상·선택/보상 발생 |
| 보스 | 2.0분 | 패턴 학습과 회피/딜링 여지 |
| 정화·보상·철수 선택 | 1.5분 | 안전하게 휴식·선택할 수 있는 정산 |
| **합계** | **10.0분** | 평균 8~12분 실측 목표 |

**위험:** 수치상 적 HP만 높여 10분을 억지로 맞추지 않는다. 첫 3개 의뢰에서 이동·대기·전투·UI 체류 시간 분포를 측정. 보스가 2분간 무적이 되는 식의 인위적 늘리기 금지.

## 8. 콘텐츠 완료 정의

각 하드웨어가 `로드 → 절차 생성 → AI 및 기믹 → 적정 보상 → 보스 패턴 → 정화 → 철수/다음 구역`을 실제로 플레이 가능해야 한다. 서로 다른 시드로 생성/도달 가능 검증, 키보드·마우스 조작, 저장 영수증, Windows 플레이 영상/로그, 8~12분 플레이 목표 측정 결과를 제출한다. **색만 변경된 5개 맵 또는 메인보드에서 5개 메뉴만 보이는 상태는 미완성이다.**
